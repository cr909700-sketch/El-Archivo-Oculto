# El Archivo Oculto — V5

Versión preparada para GitHub Pages.

Incluye:
- catálogo histórico interactivo
- buscador, filtros y cronología
- atlas, dossiers, conexiones y quiz
- favoritos y historial local
- enlaces compartibles por acontecimiento (`#evento=...`)
- PWA instalable en navegadores compatibles
- caché básica para uso con conectividad limitada
- manifest, iconos, favicon, robots.txt y sitemap.xml

## Publicación

Subir todos los archivos de esta carpeta a la raíz del repositorio de GitHub Pages y publicar desde `main` / `/ (root)`.
